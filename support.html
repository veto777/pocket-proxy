Connect over USB

  1. Connect the iPhone to your computer with a cable and tap Trust if the iPhone asks.
  2. Install iproxy on the computer: brew install libimobiledevice (Mac) or sudo apt install libusbmuxd-tools (Linux).
  3. Open Pocket Proxy and tap Start Proxy.
  4. On the computer run iproxy 1080 1080 and leave it running.
  5. Set your app to use SOCKS5 proxy 127.0.0.1:1080 with the username and password shown in Pocket Proxy. To test: curl -x 'socks5h://USER:PASS@127.0.0.1:1080' https://api.ipify.org (the app's "How to connect your computer" screen shows this command with your details filled in).

Connect over Wi-Fi

Turn on Allow Wi-Fi connections in Pocket Proxy, start the proxy, and use the Wi-Fi address shown in the app from a computer on the same network. Allow local network access when the iPhone asks.

Common questions

The proxy stopped answering. iPhone pauses apps that are not on screen. Keep Pocket Proxy open; it keeps the screen on while the proxy runs. For a phone that stays plugged in, Guided Access (Settings › Accessibility › Guided Access) keeps the app on screen.

"No cellular data connection". Check that Cellular Data is on in Settings and that Pocket Proxy is allowed to use it (Settings › Cellular › Pocket Proxy).

Does it use my data plan? With "Send traffic over cellular only" on (the default), yes: everything sent through the proxy goes over cellular data. The app shows how much went through the proxy this session; your carrier's count also includes network overhead.

Which apps work? Apps and tools that support SOCKS5 with a username and password, such as curl and Python. Some browsers, including Chrome, don't support SOCKS5 passwords. Only TCP is supported, not UDP.

Is Wi-Fi mode safe? SOCKS5 sends the username and password without encryption, so use Wi-Fi connections only on networks you trust. The USB cable is safer.
